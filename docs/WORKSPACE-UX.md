## 用户流程

运行概览发现服务、账号、资源问题 → 自动化中心选择模板 → 配置时间、阈值和通知对象 → 保存为暂停状态 → 试运行查看采样结果 → 启用 → 在运行记录查看执行与通知结果。

导航保留账号额度、用量分析、磁盘维护、资源管理、请求记录、模型路由和飞书分享；新增自动化中心。共享字体、按钮、卡片、间距、键盘焦点和窄屏横向导航。深浅主题继续使用现有设置。

## 已实现能力

| 模板 | 执行内容 | 通知规则 |
| --- | --- | --- |
| 定时提醒 | 自定义文字 | 每次到期 |
| 运行日报 | 服务在线状态、各固定磁盘剩余空间 | 每次到期 |
| 服务监控 | 协调器、数据面健康检查 | 初次异常、异常变化、恢复 |
| 磁盘监控 | 固定磁盘剩余 GB 与配置阈值比较 | 初次异常、受影响磁盘变化、恢复 |

时间规则支持每 1–10080 分钟、每天 HH:MM；采用主机本地时区，界面显示 UTC 偏移。任务可搜索、编辑、暂停、启用和删除。删除保留历史记录。编辑重新计算下次执行时间。

通知可关闭（仅记录），或显式选择已保存的飞书用户/群。飞书设置提供“添加我自己”，使用已绑定用户的 openId，不猜测身份。首次连接仍需用户完成飞书授权。新建任务默认暂停且关闭发送。

## 运行与恢复约定

调度器随 Dashboard 运行，每 5 秒检查到期任务，串行执行。关闭浏览器不影响调度；退出 Dashboard 或电脑休眠时不执行。重启/唤醒后，逾期任务补一次，不补发所有历史周期。尚未提供任意 Shell、cron 表达式、每周规则和无人值守代码任务恢复。

任务和记录保存到 runtime 数据目录的 automations.sqlite3，与账号路由数据库分离。任务执行前保存下一次时间与运行记录；异常保留失败详情，保留最近 500 条记录，界面显示最近 100 条。试运行不发送消息、不改变告警状态或下次计划。

飞书复用 lark_integration.share 的身份与幂等键，发送前重新检查收件人。部分发送失败不自动重复整批，以免给已成功对象刷屏；失败详情保留在记录中。进程中断后的发送结果可能未知，显示“执行中断”，不宣称已送达。监控中连续不变的异常不会周期性重复提醒。
